# Rhythm Trainer

Android-тренажёр ритма с метрономом, нотными рисунками и полиритмами.

Установочные APK публикуются в [GitHub Releases](https://github.com/alekseirozdobudko-cell/rhythm-trainer/releases).

Для следующих версий в приложении предусмотрена кнопка «Проверить обновление». Android запросит подтверждение установки.
